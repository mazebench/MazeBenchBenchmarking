How Solutions works

Choose a starting room in the popup when beginning a new solution. Each room begins at its authored player position with its original blocks. Each starting room keeps its own local routes. A solution starting outside H×I proves reachability from that room, not from the game's usual start.

Enter rooms to visit them. Green rooms are visited. Only visited rooms and their accessible spawn points can be selected.

Full solution combines saved runs using up, down, left, right, and go to room. A room must be visited before go to room can return to its original start. Saved spawns expand into all setup moves from the chosen start or a room start.

Spawn points are created automatically only when entering a room. Gems and planned route endpoints never create selectable spawns. Selecting a room start or saved spot resets the room; collected gems stay removed. Ice and punch moves finish before a spot can resume.

Undo removes the last move, including moves in generated routes. Use Z or ⌘/Ctrl+Z. It restores the previous room and board; other saved branches are kept.

Tap a tile to automatically find and follow an A* route. You can adjust its coordinates and search again if needed. Search runs in the background and every saved route is replayed with the engine. Use Search time beside the search buttons for harder puzzles, up to an hour or without a time limit; cancel at any time. A time or memory limit does not mean a destination is unreachable. Routes are valid, but not guaranteed shortest.

Remove solution & restart in the top row asks for confirmation before stopping verification, removing the current solution, and opening the starting-room picker for a new run.

Spots and routes save automatically in this browser. Import JSON reads the file's starting room and opens that solution automatically. If that room already has saved moves, you can review the replacement before importing. Export keeps a portable copy with the chosen starting room and move sequences. Changing the world or engine starts a separate collection.
