How Solutions works

Start at H×I and enter rooms to visit them. Green rooms are visited. Only visited rooms and their accessible spawn points can be selected.

Full solution combines saved runs using up, down, left, right, and go to room. A room must be visited before go to room can return to its original start. Saved spawns expand into all setup moves from the game start or a room start.

Spawn points are created automatically only when entering a room. Gems and planned route endpoints never create selectable spawns. Selecting a room start or saved spot resets the room; collected gems stay removed. Ice and punch moves finish before a spot can resume.

Undo removes the last move, including moves in generated routes. Use Z or ⌘/Ctrl+Z. It restores the previous room and board; other saved branches are kept.

Tap a tile to automatically find and follow an A* route. You can adjust its coordinates and search again if needed. Search runs in the background and every saved route is replayed with the engine. Use Search time beside the search buttons for harder puzzles, up to 10 minutes; cancel at any time. A search limit does not mean a destination is unreachable. Routes are valid, but not guaranteed shortest.

Clear all runs removes every saved run, discovered spawn point, and current move, then starts fresh at H×I.

Spots and routes save automatically in this browser. When your solution is empty, Import JSON restores a previously exported solution. Export keeps a portable copy with move sequences from H×I. Changing the world or engine starts a separate collection.
